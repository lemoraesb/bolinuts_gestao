# 🍰 Bolinuts Gestão

Sistema de gerenciamento de pedidos desenvolvido para auxiliar na organização de encomendas, pagamentos e entregas da Bolinuts.

## 📌 Sobre o projeto

O Bolinuts Gestão é uma aplicação desenvolvida em Python e Streamlit, integrada ao MongoDB, com o objetivo de facilitar o gerenciamento de pedidos, acompanhamento financeiro e controle de entregas.

## 🚀 Funcionalidades

- Cadastro de pedidos
- Edição de pedidos
- Consulta de pedidos
- Controle de pagamentos parciais e totais
- Cálculo de valores pendentes
- Controle de entregas
- Relatórios e gráficos de vendas
- Exportação de relatórios
- Geração de recibos em PDF

## 🛠️ Tecnologias utilizadas

- Python
- Streamlit
- MongoDB
- PyMongo
- Pandas
- Plotly
- ReportLab
- Git e GitHub
